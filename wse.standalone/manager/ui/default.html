Stream Config Defaults

Service Connection
Settings that apply to all streams unless overridden per-stream. Environment variable placeholders (e.g. ${VIS_API_KEY}) are resolved at runtime.
WebSocket endpoint for the Video Intelligence Service (VIS). Supports ${ENV_VAR} substitution.
Sent as X-API-KEY header. A stored key is never shown, so the value field is blank even when one is set; a blank field keeps it. Or pick a stored secret: the name is readable, and rotating it on the Secrets page applies on the next connect.
Video Processing Defaults
Default frames per second sent for analysis. Set to -1 to match each stream's frame rate. Per-stream configs can override this value.
When enabled, frames are pulled from the transcoder output instead of the incoming stream.
Seconds between frame grabs when not using the transcoder. Set to the GOP of the incoming stream.
Scene/VLM only. Length of the clip sent to the Video Intelligence Service (VIS) per analysis request.
Concurrent Executions
Max simultaneous object detection inferences. Increase if GPU usage stays below 50% at full load.
Max simultaneous scene detection inferences.
Verify Defaults
The baseline every Verify stream config and on-demand Verify job inherits where it leaves a field blank: the scoring endpoint, the gate and the review model. Optional — a blank field keeps the built-in default shown as its placeholder, and clearing a stored value removes it. Environment variable placeholders (e.g. ${NVCF_API_KEY}) are resolved at runtime.
Stage 1 — Scoring (NVIDIA Synthetic Video Detector)
SVD NIM as a gRPC host:port, not an http URL. Local sidecar svd.docker:8001; NVIDIA hosted grpc.nvcf.nvidia.com:443. There is no built-in default: a Verify job needs it here or on its own config.
Bearer token for the hosted NVCF endpoint. A stored key is never shown; leave blank to keep it. Or pick a stored secret: rotating it on the Secrets page applies with no config change.
NVCF function id, sent as function-id metadata; hosted endpoint only.
Gate — which windows Stage 2 reviews
A window is flagged, and reviewed, when its synthetic score exceeds this (0.0–1.0).
Scores above this count as synthetic even if the review disagrees; the review then only explains why (0.0–1.0, at or above the flag threshold).
Stage 2 — Review (vision-language model)
The NVIDIA model that reviews flagged windows; Verify's prompts are tuned for these. Must match a model the server serves.
Address of the reviewing model's server (e.g. vlm.docker:8000). If omitted, http:// and the /v1 path are added on save.
Sent as a bearer token. A stored key is never shown; leave blank to keep it. Or pick a stored secret: rotating it on the Secrets page applies with no config change.
Seconds to wait for one review answer.
