Secrets — the stored-credentials document

One flat namespace of stored credentials the configuration references by name: VLM/SVD endpoint keys, the service key, the SVD TLS client key and VOD webhook Authorization values. A value is written once and never read back; rotating it here applies to the next connect or delivery with no config change. Removing a name that a config still references is refused, listing every place that uses it.

These secrets share one trust boundary — the Engine's REST admin realm. Anyone holding the Engine REST credentials can point a config at a URL they control and have any stored secret sent to it, so treat access to this Manager as access to every value stored here.
